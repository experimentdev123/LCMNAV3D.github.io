# SEO setup and launch checklist

Everything in this file is about getting `https://lcmnav3d.github.io/` indexed and
ranking. The on-page work is already done and is regenerated by `tools/build.js`.

## 1. The hostname must match, exactly

Every canonical URL, the sitemap, the feed and the structured data hardcode
`https://lcmnav3d.github.io`. That address only exists if the repository is named
**`lcmnav3d.github.io`** and lives under a GitHub account or organisation named
**`lcmnav3d`**.

The repository is currently `experimentdev123/LCMNAV3D.github.io`, which GitHub
serves from `https://experimentdev123.github.io/LCMNAV3D.github.io/` instead. Until
that is resolved, every canonical tag points at a 404 and **nothing will index**.

Pick one:

- **Move the repo** to an account/org named `lcmnav3d`, repo `lcmnav3d.github.io`.
  Nothing else changes.
- **Keep the current account** and change `SITE` at the top of `tools/build.js` to
  `https://experimentdev123.github.io/LCMNAV3D.github.io`, then re-run the build.
- **Use a custom domain**, set `SITE` to it, add a `CNAME` file containing the
  hostname, and point DNS at GitHub Pages.

Verify after deploying:

```bash
curl -sI https://lcmnav3d.github.io/ | head -1              # expect 200
curl -s https://lcmnav3d.github.io/ | grep -i canonical      # must match the real URL
curl -sI https://lcmnav3d.github.io/nope | head -1           # expect 404
```

## 2. Turn on GitHub Pages

Repository → Settings → Pages → Source: *Deploy from a branch* → `main` / `/ (root)`.
Enforce HTTPS. `.nojekyll` is present, so files are served exactly as committed.

## 3. Google Search Console

1. Go to <https://search.google.com/search-console> → **Add property** → **URL prefix**
   → `https://lcmnav3d.github.io/`.
2. Choose the **HTML tag** method and copy the `content="..."` value.
3. Paste it into `GSC_VERIFICATION` at the top of `tools/build.js`, run
   `node tools/build.js .`, commit and push.
4. Back in Search Console, press **Verify**.
5. **Sitemaps** → submit `sitemap.xml`.
6. **URL Inspection** → paste the home page URL → **Request indexing**. Do this once
   for the home page; the rest follows from the sitemap and internal links.

Domain-level verification via DNS is not available on a `github.io` subdomain — the
HTML tag method is the one to use.

## 4. Bing

<https://www.bing.com/webmasters> supports importing the verified property straight
from Search Console, which is the fastest route. Bing also feeds DuckDuckGo.

## 6. Things worth knowing

- **`FAQPage` earns no rich result on Google.** Google restricted FAQ rich results to
  recognised government and health sites in August 2023. The markup is still correct
  and is consumed by Bing and by AI answer engines, which is why it is there — but do
  not expect FAQ accordions in Google results.
- **`rel="prev"`/`rel="next"` is deliberately absent.** Google announced in 2019 that
  it does not use those hints for indexing, so they would be dead weight.
- **`og.png` (2.1 MB) is no longer referenced.** `og.jpg` (149 KB) replaced it. The
  PNG is kept as the master; it can be deleted from the working tree without
  affecting the site.
- **Ranking needs links.** On-page SEO makes the site eligible; it does not make it
  rank. The highest-value next step is a link to `https://lcmnav3d.github.io/` from
  the Fab listing, the YouTube video description, the Discord server, and
  `uedevlabs.github.io` — that last one especially, since it is an already-indexed
  site on a related topic.
- **Do not hand-edit generated metadata.** `tools/build.js` will overwrite it. Edit
  `tools/seo-pages.js` instead.
